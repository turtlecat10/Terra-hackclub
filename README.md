# Terra-hackclub

A text-based uno game written in Java, choose between standard uno, uno no mercy and uno all wild. Play directly in your terminal (make sure that when another little window appears click it to be able to use arrow keys to move), using arrow keys to change which card/action you want to do, use space to select/deselect cards for play, and press enter to confirm action.

---

Prerequisites

Before playing, make sure you have the **Java Development Kit (JDK 8 or higher)** installed. 

To verify if Java is installed, open your terminal or command prompt and run:
```bash
java -version
javac -version
```

---

How to Download and Setup

1. Clone the Repository
Open your terminal or command prompt and run:
```bash
git clone https://github.com
cd Terra-hack-club.git
```
*(Alternatively, click the green **Code** button on GitHub, select **Download ZIP**, and extract the contents to a folder on your computer).*

---

Running the Game

You can compile and run the game directly using the standard Java compiler. 

Step-by-Step Instructions:

1. Open your terminal or command prompt and ensure you are inside the `Terra-hack-club` root directory.
2. Compile the Java files:
   ```bash
   javac *.java
   ```
3. Launch the game:
   ```bash
   java Main
   ```

---

🕹️ How to Play

* The game runs entirely inside your terminal window.
* Follow the on-screen text prompts.
* Type your inputs, choices, or commands directly into the terminal and press **Enter** to submit.
